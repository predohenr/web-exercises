Esta página não funciona no GitHub Pages. Este projeto requer um servidor backend com banco de dados e não pode ser executado como uma página estática.

Para rodar localmente, você precisa:
  1. Instalar o Node.js
  2. Criar um banco de dados no Neon e copiar a connection string
  3. Criar um arquivo .env na pasta backend/ com: NEON_URL=sua_connection_string
  4. Rodar npm install e depois node server.js dentro da pasta backend/
  5. Abrir o arquivo frontend/index.html no navegador
